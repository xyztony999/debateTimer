## 与现行 v2 的差异（全部在 CSS 状态块 + 少量 JSX）

### 1. CSS：`src/timer/timer-control.css` 重写 PID 状态块

- **D11 全线一色带**：`--st-line` 直接用线路色（浅 `#1e3a5f` / 暗 `#90caf9`），所有 `.st-step::after` 段统一一色；删除 `.st-step--passed::after` 分段着色。7px 粗带、端帽 stub、光环断带（box-shadow halo）沿用 v2。
- **D12 已过褪灰（状态反转）**：
  - 未来站 = 白芯 + 线路色环 + 正常色站名（MTR 珠子）
  - 已过站 = 灰环灰芯 + 灰站名（现在的"未来"样式挪给已过，未来换新样式）
  - 当前站 = 实心线路色圆盘（halo 断带）+ 站名线路色加粗；**删除 v2 的反色胶囊站名**
  - 删除 st-pulse/st-pulse-dark 圆环脉冲（由车标接管生命感）
- **D13 车标当前位置**：`.st-step--current` 内渲染 MUI `TrainRounded` 图标（accent 色，约 0.95rem，绝对定位在当前站圆点上方，容器顶 padding 加高 ~0.5rem 容纳），2.5s 缓慢透明度呼吸；图标不可用时退 CSS 箭头。
- **D14 下一站提示条**：时间线下方右对齐小字条 `.st-next`：`下一站 · <下一阶段名>`；当前已是最后一站时显示 `终点站 · <当前阶段名>`；0.75rem、text.secondary、前缀小箭头 ›。
- **D15 换乘站胶囊**：`.st-step--interchange .st-dot` 从大圆环改港铁官方画法——横向胶囊（约 2.3×1.55rem，圆角 999px，3px 线路色环，底色芯，芯内线路色站号）；已过=灰环灰号；当前+换乘=实色胶囊反色号；上移补偿使点心共线（沿用 v2 的 margin-top 技法）。
- 移动端/触屏/横滑/两行站名/≥44px 规则不动。
