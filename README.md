# 辩论赛计时器 Debate Match Timer

因 React 的 Create React App 已被官方弃用，本项目已迁移至 **Vite** 构建，并使用 **Bun** 作为包管理器与脚本运行工具。网页通过 GitHub Actions 自动构建并部署。`master` 分支为主程序，`deploy/production` 分支为封装的静态网页版本。

## 简介

本项目根据渥太华大学华语辩论社（UOMDC）的比赛规则制定并执行

访问地址：[https://debatetimer.tonyxyz.com](https://debatetimer.tonyxyz.com)

## 开发命令

需先安装 [Bun](https://bun.sh/)，然后在项目根目录执行：

| 命令 | 说明 |
|------|------|
| `bun install` | 安装依赖 |
| `bun start` | 启动开发服务器 |
| `bun run lint` | 运行 ESLint 检查 |
| `bun test` | 运行测试 |
| `bun run build` | 构建生产版本 |

## 目前功能

本项目目前已完成如下功能

### 黑暗主题
在启动黑暗模式的系统上，计时器将自动切换为黑暗模式。亦支持手动调整，并会记住你的选择。

### 切换辩论阶段

1. 点击上方的下拉菜单切换，或使用 ← / → 快捷键切换上一 / 下一阶段
2. 在设置页可自由添加、删除、更改比赛阶段、时长与单/双计时模式，并支持拖拽调整阶段顺序

### 配置模板

1. 支持新建、切换、保存修改与删除辩论流程模板（默认模板不可删除）
2. 模板数据存放于自建 MongoDB API，计时器页与设置页会同步当前模板
3. 提供服务端配置导入脚本（`server/scripts/import-configurations.js`）便于批量导入

### 多语言支持
- 支持语言：中文、英文、法语（加拿大）
- 自定义阶段名称可分别填写多语言文案

### 操作倒计时启动、暂停、重置

1. 点击每个阶段中的按钮

2. 键盘快捷键：
   - **单计时器模式**：空格（启动/暂停）、Shift+R（重置）
   - **双计时器 / 自由辩论模式**：A（正方启停）、Shift+Q（正方重置）；L（反方启停）、Shift+O（反方重置）
   - **切换阶段**：←（上一阶段）、→（下一阶段）

### 自由辩论自动切换

1. 在设置页可将阶段计时模式设为「自由辩论（自动切换）」
2. 显式停止一方（按钮或 A / L）后，另一方自动开始计时
3. 一方时间耗尽自动切换至对方；双方均耗尽则环节锁定，重置后恢复手动操作

### 超时宽限（grace period）

1. 阶段可配置宽限秒数（0–300，默认关闭）
2. 时间到 → 短铃 + 橙色闪烁进入宽限收尾倒计时；宽限耗尽 → 长鸣 + 红色闪烁锁定（铃声语义区分「时间到 / 必须停」）
3. 宽限相位经快照同步到大屏；单 / 双 / 自由辩论计时均适用

### 提示音自定义

1. 按告警节点（30 秒提醒 / 时间到 / 必须停）分别选择铃声方案与音量，可试听
2. 偏好保存在本设备（控制端与显示端各自配置）；设置页与大屏页均有入口

### 队名显示与自动推进

1. 模板可配置正反方队名，计时页与大屏以「正/反徽标 + 队名」展示
2. 阶段可开启「自动进入下一阶段」：阶段彻底结束（含宽限）3 秒后自动切换，期间任意操作取消；最后一个阶段不推进

### 大屏实时同步（控制会话）

1. 计时操作员在计时页「开启大屏同步」后，可用手机 / 电脑远程控制计时
2. 分享链接打开的大屏在会话期间**只读跟随**：实时显示当前阶段与倒计时（本地插值 + 心跳校准），30 秒提醒与结束铃声同步
3. 断线自动重连并重新校准；会话结束（主动停止 / 心跳超时 / 分享停用）后，大屏提示并回退为独立计时页
4. 无活跃会话时，分享页保持原有独立计时行为；旧版本前端遇到「自由辩论」模式按双计时降级

### 比赛记录与复盘

1. 计时过程自动累计每阶段实绩：计划 vs 实际用时（正反方分开）、超时次数（宽限耗尽计超时）
2. 计时页「保存记录」随时提交快照式记录；控制会话结束时自动保存
3. 「比赛记录」页：历史列表 + 阶段明细对比 + CSV（Excel 中文兼容）/ JSON 导出 + 删除；模板与队名以快照留存，赛后改模板不影响历史

### 模板广场（公开赛制库）

1. 设置页可将模板「发布到模板广场」；广场匿名可浏览（不显示归属人信息）
2. `/gallery`：卡片列表（阶段数/总时长/模式构成）+ 详情 + 一键「复制到我的模板」
3. 管理员可强制下架；导入脚本支持 `--public`，`server/scripts/presets/` 预置 UOMDC/BP/奥瑞冈样例赛制

### PWA 与手机适配

1. 可安装到桌面 / 主屏幕；断网时应用壳离线可用（计时核心不依赖网络，API 数据不缓存）
2. 离线时顶部红色横幅提示「计时可用，云同步暂不可用」
3. 触屏优化：隐藏键盘快捷键提示、加大按钮触达区；小屏秒表字号自适应

### 在倒计时还有30秒和结束时

- 在倒计时还有30秒时，时间会闪烁3秒，并会播放提示音
- 在倒计时结束时，时间会持续红色闪烁提示，并会播放提示音

## 生产部署

推送 `deploy/production`：

- **前端**：GitHub Pages（`.github/workflows/deploy.yml`）
- **API / MongoDB**：宝塔，`deploy.sh --api-only`（[说明](deploy/baota/README.md)）

```bash
bash /www/wwwroot/debatetimer-api/deploy/baota/deploy.sh --api-only
```

### 数据备份（服务器 cron）

`server/scripts/backup.js`：纯驱动导出 `configurations / users / match_logs` 为 NDJSON 快照（`server/backups/`），保留 14 天自动轮换；`--restore <名称> --force` 整库回放（含 ownerId 深层复活）。服务器 crontab 示例：

```bash
30 4 * * *  cd /www/wwwroot/debatetimer-api/server && node scripts/backup.js >> /www/wwwlogs/debatetimer-backup.log 2>&1
```

## 技术栈

- 前端：React + Vite + Bun；设置页使用 Material UI
- 后端：Express + MongoDB（配置模板 API）
- 部署：前端 GitHub Pages（`deploy/production`）；API 宝塔脚本见 [`deploy/baota/README.md`](deploy/baota/README.md)
