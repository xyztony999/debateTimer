## 第一部分：文档概述

本文档描述辩论赛计时器的业务架构。系统依据渥太华大学华语辩论社（UOMDC）比赛规则，
为辩论赛现场提供流程模板配置、阶段计时与多屏协同展示能力。

### 1.1 背景与目标

辩论赛现场需要一个可信的计时工具：主席按赛程推进各阶段发言计时，观众与辩手通过大屏
看到当前环节与剩余时间。业务架构设计目标：

1. 将「赛前配置 → 现场计时 → 大屏展示」的业务闭环结构化
2. 支撑多端协同：一人操作计时、多屏只读跟随
3. 覆盖 UOMDC 赛制全部环节类型，含自由辩论的交替计时规则

### 1.2 文档定位

| 定位 | 说明 |
|------|------|

## 第二部分：业务架构

> 本章按 L2→L3→L4 逐层描述业务架构。每层有其概述和业务说明。

### 本架构概览

业务闭环为：赛前准备阶段完成赛程模板与分享设置，形成「可执行的赛程」；比赛执行阶段
基于模板展开计时控制，并通过实时协同将计时状态同步到大屏；系统支撑阶段保障账号与
数据归属安全。比赛执行是价值主链，赛前准备为其输入，系统支撑为其底座。

### 2.1 赛前准备

**业务说明**：将一套比赛规则转化为可执行的赛程模板，并准备好现场多屏所需的分享链接。
该阶段产出「流程模板」与「分享设置」，是比赛执行的直接输入。

##### 2.1.1 流程模板管理

**业务说明**：维护辩论流程模板——阶段的有序集合，含每个阶段的时长与计时模式。
默认模板（UOMDC 官方赛制）受保护不可删除。所属 L2：赛前准备。

###### 2.1.1.1 模板生命周期管理

**业务说明**：模板的新建、切换、保存修改与删除；默认模板不可删除。所属 L3：流程模板管理。

###### 2.1.1.2 阶段定义管理

**业务说明**：添加、删除、修改比赛阶段；设定各阶段时长与计时模式
（单计时 / 双计时 / 自由辩论）。所属 L3：流程模板管理。

###### 2.1.1.3 阶段顺序管理

**业务说明**：拖拽调整阶段先后顺序，决定现场推进次序。所属 L3：流程模板管理。

###### 2.1.1.4 阶段多语言文案管理

**业务说明**：自定义阶段名称按中文、英文、法语（加拿大）分别填写文案。所属 L3：流程模板管理。

###### 2.1.1.5 模板批量导入

**业务说明**：通过服务端脚本批量导入模板数据，便于赛制预置与迁移。所属 L3：流程模板管理。

##### 2.1.2 分享设置管理

**业务说明**：控制模板的大屏访问方式——生成、轮换、停用分享令牌，向现场分发展示链接。
分享设置是显示端访问的前提。所属 L2：赛前准备。

###### 2.1.2.1 分享开关与令牌管理

**业务说明**：启用/停用分享；令牌的生成与轮换（旧令牌随之失效）。所属 L3：分享设置管理。

###### 2.1.2.2 大屏链接分发

**业务说明**：获取展示链接并分发给现场（复制/二维码场景）；链接失效时的提示。所属 L3：分享设置管理。

### 2.2 比赛执行

**业务说明**：比赛现场按赛程推进计时，并将计时状态实时同步至大屏。这是业务价值主链：
计时控制的准确性、提示告警的及时性、多屏展示的一致性共同构成「可信计时」。

##### 2.2.1 阶段计时控制

**业务说明**：对当前比赛阶段执行计时——按阶段计时模式驱动单方或双方倒计时，
支持快捷键操作，并在关键时间点发出提示告警。所属 L2：比赛执行。

###### 2.2.1.1 单计时控制

**业务说明**：单方发言环节的启动/暂停/重置；快捷键操作（空格启停、Shift+R 重置）。所属 L3：阶段计时控制。

###### 2.2.1.2 双计时控制

**业务说明**：正反双方对立环节（如对辩、盘问）的各自独立启停与重置
（A/L 启停、Shift+Q / Shift+O 重置）。所属 L3：阶段计时控制。

###### 2.2.1.3 自由辩论计时控制

**业务说明**：自由辩论环节的交替自动计时——显式停止一方即自动启动对方计时；
一方时间耗尽自动切换至对方；双方均耗尽则本环节结束。支持手动重置恢复常规操作。所属 L3：阶段计时控制。

###### 2.2.1.4 比赛阶段切换

**业务说明**：在赛程内切换当前阶段（下拉选择或 ← / → 快捷键），切换时重置计时上下文。所属 L3：阶段计时控制。

###### 2.2.1.5 计时提示告警

**业务说明**：剩余 30 秒时的闪烁与提示音；时间耗尽时的持续红色闪烁与提示音。所属 L3：阶段计时控制。

##### 2.2.2 实时协同展示

**业务说明**：将控制端的计时状态实时同步到大屏——控制端发起控制会话并持续上报状态
快照，显示端跟随渲染；同时保留无会话时的独立展示模式。所属 L2：比赛执行。

###### 2.2.2.1 控制会话管理

**业务说明**：控制端基于某个流程模板开启/结束控制会话；会话是状态同步的作用域与寻址单元。所属 L3：实时协同展示。

###### 2.2.2.2 计时状态上报

**业务说明**：控制端将当前阶段、计时模式、双方剩余时间、运行标志、活跃阵营等状态
以快照形式上报，状态变化即上报并辅以周期心跳。所属 L3：实时协同展示。

###### 2.2.2.3 大屏跟随展示

**业务说明**：会话活跃时，显示端按最新快照只读渲染倒计时（本地插值，断流不跳变）。所属 L3：实时协同展示。

###### 2.2.2.4 断线恢复

**业务说明**：显示端断线重连后先拉取最新快照再继续跟随；控制端离线超时后会话失活，
显示端回退。所属 L3：实时协同展示。

###### 2.2.2.5 大屏独立展示

**业务说明**：无活跃会话时，显示端作为匿名独立计时页使用（加载分享的模板自行计时）。所属 L3：实时协同展示。

### 2.3 系统支撑

**业务说明**：保障系统访问安全与数据归属，支撑赛前准备与比赛执行的正常开展。

##### 2.3.1 账号与访问管理

**业务说明**：用户身份认证与数据归属隔离；管理员可管理用户与代管配置。所属 L2：系统支撑。

###### 2.3.1.1 登录与登出

**业务说明**：用户登录获取会话，登出失效；受保护页面要求认证。所属 L3：账号与访问管理。

###### 2.3.1.2 数据归属与隔离

**业务说明**：模板等数据按归属人隔离；跨归属访问受权限策略限制。所属 L3：账号与访问管理。

###### 2.3.1.3 用户管理

**业务说明**：管理员查看、创建、停用用户账号。所属 L3：账号与访问管理。

### 附录B：业务术语表

| 术语 | 定义 | 备注 |
|------|------|------|
| 比赛阶段（Stage） | 计时单元：名称、时长、计时模式 | 计时模式含单/双/自由辩论 |
| 流程模板（Template） | 阶段的有序集合；默认模板不可删除 | 存于配置文档 |
| 单计时 | 单方发言计时模式 | |
| 双计时 | 正反双方对立计时模式 | 各自独立启停 |
| 自由辩论 | 交替发言计时模式：停止一方自动启动对方 | 本次新增 |
| 控制端 | 计时操作员操作计时所用的认证设备 | |
| 显示端/大屏 | 匿名只读访问的展示屏幕 | 经分享链接进入 |
| 控制会话 | 状态同步的作用域：控制端开启、绑定模板、有生命周期 | 本次新增 |
| 计时状态快照 | 某一时刻计时状态的完整切面（阶段/剩余时间/运行标志/序号） | 本次新增 |
| 跟随模式 | 显示端按控制会话快照只读渲染的状态 | 本次新增 |
| 独立模式 | 无会话时显示端匿名自用的状态 | 即现有行为 |
| shareToken | 分享令牌，显示端寻址配置与会的钥匙 | 既有 |
