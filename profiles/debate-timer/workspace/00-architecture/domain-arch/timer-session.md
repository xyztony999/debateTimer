# 领域模型 — 计时协同域（D2-2 领域建模）

|------|-----|
| 版本 | v1.0 |
| 日期 | 2026-10-10 |

## 本域信息（必输出）

| 项目 | 内容 |
|------|------|
| 本域名称 | 计时协同（隶属比赛执行核心域） |
| 领域分层 | 核心域（比赛执行主链环节，有运行态状态机） |
| 聚合根 | 控制会话（TimerSession） |

PRD 标注模块明确（C-02），**跳过战略设计 Step 1~3**，直接进入战术设计。

## Step 0 范围判定

PRD 标注所属模块：C-02 实时协同展示（+C-01-03 前端规则扩展）→ 范围明确，单一业务模块。

## Step 4 前置过滤：过程数据

| 数据项 | 类别 | 处理方式 |
|--------|------|---------|
| 控制端本地计时 state（timeLeft/running 等） | P3 UI 交互状态 | 前端本地，不入领域模型；仅作快照组装来源 |
| 显示端钟偏估计（clockOffset） | P7 计算中间值 | 前端本地推导，随快照重建 |
| 显示端插值后的展示剩余时间 | P7 计算中间值 | 视图层派生 |
| SSE 连接对象 / 重连状态 | P6 平台托管 | 通道层管理 |
| 「信号弱」「会话已结束」提示标志 | P3 UI 交互状态 | 视图层 |
| 自由辩论自动切换的挂起标志 | P3 UI 交互状态 | 前端计时器内部行为，非持久对象 |

## Step 5 聚合根识别（A1–A4）

| 测试 | 结果 | 说明 |
|------|------|------|
| A1 一致性边界 | ✓ | 快照缓存与会话状态必须一致（seq 单调、失活即停发） |
| A2 全局引用 | ✓ | 显示端按 shareToken 引用会话；sessionId 全局唯一 |
| A3 生命周期入口 | ✓ | 快照只能经会话写入（上报接口校验归属与会话存续） |
| A4 规则驱动 | ✓ | 失活规则（心跳/分享停用）驱动大屏行为回退 |

判定：**4/4 → 聚合根：控制会话（TimerSession）**

## Step 6 域内对象分类

| 对象名 | 分类 | 与上级关系 | 核心业务字段 | 关键枚举字段 | 备注 |
|--------|------|-----------|------------|------------|------|
| 计时状态快照 | **值对象** | 隶属控制会话（仅保留最新） | seq, stageId, stageMode, remainingAffMs/NegMs, runningAff/Neg, activeSide, serverTime | stageMode, activeSide | 不可变、按值等价、整体替换；**不持久化**（随会话存于内存） |
| 会话元数据 | 实体属性（不独立建模） | 聚合根内嵌 | sessionId, configId, configName, shareToken, ownerId, status, startedAt, lastSeenAt | status | 内聚于聚合根，无独立标识需求 |

判定依据（实体 vs 值对象）：快照无个体标识、同值即等价、只替换不修改 → 值对象。

## Step 7 子流程识别

无。会话生命周期（active→ended/expired）为聚合根自身状态机，无独立生命周期的子过程。

## Step 8 关联领域对象

| 关联领域对象 | 所属业务域 | 当前域关联字段 | 当前域需要获取的信息 | 触发关系 | 映射模式 |
|------------|-------------|-------------|------------------|---------|---------|
| 配置文档（流程模板聚合根） | 支撑业务域-流程模板管理 | configId, configName, shareToken（冗余） | 阶段定义（stageId→时长/模式/多语言文案）、分享可见性 | 会话开启时校验归属与分享；显示端经 toDisplayResponse 消费 | 遵奉者（直接消费配置响应契约，不建翻译层） |

关联域内部模型不在本文档展开（见其自身 PRD/API 文档）。

## Step 9 跨业务域集成

| 边界 | 模式 | 实现 |
|------|------|------|
| 会话 ↔ 流程模板域 | 遵奉者 | 复用 `configurations` 集合查询与 `toDisplayResponse` 投影 |
| 会话 ↔ 展示端 | OHS + PL | `GET /api/display/:token/state`（拉取）+ SSE `state` 事件（推送）；快照 JSON 即发布语言 |
| 会话 ↔ 权限域 | 遵奉者 | 复用 `requireAuth` + `canAccessConfig` + CSRF 中间件 |

## 领域事件

| 事件 | 载荷 | 消费方 |
|------|------|--------|
| SessionStarted | sessionId, shareToken, 初始快照 | 显示端（进入跟随模式） |
| SnapshotUpdated | 快照 | 显示端（校准插值） |
| SessionEnded / SessionExpired | sessionId, shareToken, 原因 | 显示端（提示并回退独立模式） |

## 常见错误对照检查

- 未把查询条件/插值状态建模为对象（✓ 已归过程数据）
- 巨型聚合根（✓ 会话仅持最新快照）
- 关联域内容未渗入当前域（✓ 仅存 configId/冗余 token）
- 「当前对象 vs 历史对象」：快照历史明确不保留（历史存档属后续迭代，PRD §3.2）
