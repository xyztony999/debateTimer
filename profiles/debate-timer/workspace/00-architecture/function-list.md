## 第一部分：文档概述

本文档按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据。

### 1.1 背景与目标

由应用架构（AA v1.0）按「用户类型 × 操作类型」展开，明确各角色可见与可操作的功能边界，
支撑本次「实时协同展示 + 自由辩论」迭代的前端页面与权限设计。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | 辩论赛计时（UOMDC 规则基准） |
| 用户类型 | 计时操作员、观众、管理员 |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

计时操作员覆盖赛前准备与比赛执行的全部操作面（模板、分享、计时、控制会话）；
观众仅经分享链接使用大屏（跟随观看或独立自用）；管理员在操作员能力之上增加用户管理
与跨归属代管。平台支撑域（实时通道/主题多语言）作为展示基座被全部用户类型使用，
不设独立菜单章节。

## 2.1 计时操作员

**用户类型概述**：认证用户，模板归属人。赛前完成模板与分享配置，现场执行计时控制
并发起控制会话驱动大屏。

#### 2.1.1 核心业务域

**应用域概述**：比赛执行价值主链——本角色的主战场。

**功能说明**：对当前阶段执行计时，按计时模式驱动倒计时并触发提示告警。

## 2.2 观众

## 3.1 计时操作员功能视图

```
计时操作员
├── 核心业务域
│   ├── 阶段计时控制
│   │   ├── 单计时控制
│   │   │   └── 单计时操作 — 启停/重置 + 快捷键
│   │   ├── 双计时控制
│   │   │   └── 双计时操作 — 正反方独立启停/重置
│   │   ├── 自由辩论计时控制
│   │   │   └── 自由辩论操作 — 停一方自动启对方；到时自动切换
│   │   ├── 比赛阶段切换
│   │   │   └── 阶段切换 — 下拉/快捷键 + 计时上下文重置
│   │   └── 计时提示告警
│   │       └── 提示告警（操作侧） — 30 秒/到时 声闪
│   └── 实时协同展示
│       ├── 控制会话管理
│       │   └── 控制会话开关 — 开启/结束会话 + 连接状态
│       └── 计时状态上报
│           └── 状态上报 — 快照事件+心跳（无独立菜单）
    ├── 支撑业务域
    │   ├── 流程模板管理
    │   │   ├── 模板生命周期管理 → 模板管理
    │   │   ├── 阶段定义管理 → 阶段编辑（含自由辩论模式）
    │   │   ├── 阶段顺序管理 → 阶段排序
    │   │   └── 阶段多语言文案管理 → 阶段文案
    │   └── 分享设置管理
    │       ├── 分享开关与令牌管理 → 分享管理
    │       └── 大屏链接分发 → 链接分发
    └── 基础数据域
        └── 账号与权限
            ├── 登录与登出 → 登录/登出
            └── 数据归属与隔离 → 归属边界（横切约束）
```
