## 第一部分：文档概述

本文档按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据。

### 1.1 背景与目标

由应用架构（AA v1.0）按「用户类型 × 操作类型」展开，明确各角色可见与可操作的功能边界，
支撑本次「实时协同展示 + 自由辩论」迭代的前端页面与权限设计。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

计时操作员覆盖赛前准备与比赛执行的全部操作面（模板、分享、计时、控制会话）；
观众仅经分享链接使用大屏（跟随观看或独立自用）；管理员在操作员能力之上增加用户管理
与跨归属代管。平台支撑域（实时通道/主题多语言）作为展示基座被全部用户类型使用，
不设独立菜单章节。

## 2.1 计时操作员

**用户类型概述**：认证用户，模板归属人。赛前完成模板与分享配置，现场执行计时控制
并发起控制会话驱动大屏。

## 3.1 计时操作员功能视图

```
计时操作员
├── 核心业务域
│   ├── 阶段计时控制
```
