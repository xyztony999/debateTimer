## 4. 页面结构（区块级）

### 4.1 会话控制条（新增区块，置于阶段下拉栏右侧）

- `Chip`（状态）：未开启（灰）/ 大屏同步中（绿，含在线大屏数提示）/ 信号弱（橙）/ 已结束（灰）
- `Button` 开启大屏同步（未开启态）｜ 结束同步 + 复制大屏链接（已连接态）
- 加载态：按钮 disabled + CircularProgress（R3 异步反馈）
- 错误态：Snackbar 展示 message（403/409/400 分别见 API 3.4.2）

### 4.2 计时主体（既有布局扩展）

| stageMode | 布局 | 说明 |
|-----------|------|------|
| single | 既有单计时布局 | 不变 |
| double | 既有双计时布局 | 不变 |
| free | 双计时布局 + 活跃方高亮 | 当前 `activeSide` 一侧加边框/亮度强调；双方均 0 显示「环节已结束」锁态文案 |

### 4.3 自由辩论操作区（`free` 模式）

- 显式停止一方（按钮或 A/L）→ 自动启动对方（无需二次操作）
- 一方归零 → 自动切换 + 提示音；双方归零 → 锁态 + 「重置」可解锁（BR-9）
- 快捷键沿用：A / L / Shift+Q / Shift+O（语义见 README 既有定义）

## 5. 状态与反馈

| 状态 | 表现 |
|------|------|
| 会话未开启 | 会话条灰色初始态；计时行为与现状完全一致 |
| 已连接 | 绿 Chip；每次操作后快照上报（seq++）；心跳 2s |
| 上报连续失败 ≥2 | 橙 Chip「信号弱」；本地计时不受影响 |
| 会话被 superseded / 409 | 提示后回到未开启态 |
| 页面刷新 | 重拉配置 + GET #4 判会话存续，active 则恢复已连接态续操作 |

## 9. v1.2 增量：融合式阶段导航（2026-10-12）

**背景**：控制台上线后用户反馈——阶段时间线 16 个胶囊从容器左缘排起、右侧溢出横滑裁切，与下方居中时钟轴线错位；下方大标题与时间线当前项重复显示同一阶段名；胶囊宽窄随名称长短参差，观感突兀。

**设计决策**：

| # | 决策 | 内容 |
|---|------|------|
| D1 | 删除重复标题行 | 移除时钟区上方的 `h5` 阶段名标题；阶段名由时间线选中胶囊承载 |
| D2 | 等宽胶囊铺满 | 未选中胶囊 `flex: 1 1 0`（等宽铺满容器，两端对齐），名称截断（ellipsis）+ `title` 全名提示；**选中胶囊加宽**（flex-grow 放大）显示完整阶段名、字重 700、维持现高亮样式 |
| D3 | 当前项居中视口 | 阶段切换后选中胶囊平滑滚动至时间线水平居中（`scrollIntoView({ inline: 'center' })`），修复"比赛进行到中后段时当前项滚出视口" |
| D4 | 移动端回退 | <768px 胶囊恢复自然宽度 + 横滑 + `justify-content: safe center`（居中对齐不裁左缘），等宽在该宽度不可用 |
| D5 | 语境按钮行 | 试铃按钮（sound_check）/ 自动推进倒计时（Alert）合并为时钟区上方一行，居中，仅在存在时渲染 |

**不变项**：Action/接口/i18n 无变更；tablist/tab 语义（aria-selected）保留；触屏适配（bundle D 口径）保留。

**验收标准**：

- [ ] 时间线与容器两端对齐，无右侧空白或固定裁切感
- [ ] 仅选中胶囊显示完整阶段名（其余截断 + title 提示）
- [ ] 切换阶段后选中胶囊位于时间线可视中心（可滚动时）
- [ ] sound_check 试铃与自动推进倒计时显示于时钟上方一行
- [ ] <768px 回退为自然宽度横滑居中；触屏 ≥44px 口径不回退

> 校验说明：v1.2 增量沿用 v1.0 校验口径（FX 清单按节人工核对），新增验收 5 条如上。

## 11. v1.4 增量：控制台跟随与接管（C-02-06，2026-10-12）

**背景**：遥控器布局上线后真机反馈"遥控器这个功能是不是得跟主程序得联动啊？"——现状
电脑开主程序首页 `/` 是独立计时，不跟随手机遥控器（且两端同开会互相抢会话）。用户确认
期望形态：**控制台跟随模式**（发现本人会话 → 跟随/接管选择）。

**设计决策**：

| # | 决策 | 内容 |
|---|------|------|
| D1 | 会话发现询问化 | 控制端初始化探测到本人活跃会话时**不再静默恢复上报**（现状 restoreLiveSession 行为改为先询问）：MUI Dialog「检测到正在进行的遥控器会话」，按钮 **跟随**（默认焦点）/ 接管 / 关闭 |
| D2 | 跟随态 | 复用 display 跟随语义（快照采纳/SSE/插值/弱信号）；保留本页布局（控制台或遥控器）但只读：计时操作与时间线禁用、显示跟随提示；顶栏跟随胶囊（绿）+「接管」入口；隐藏「开启大屏同步」入口（跟随端不能兼任控制端） |
| D3 | 接管 | 弹层或胶囊中点接管 → 采纳快照并续接上报（现有 restore 原语），胶囊转「大屏同步中」；原遥控端因快照 seq 冲突在心跳 400 后判会话结束、自动保存并回独立模式（≤4s，无需新通知通道） |
| D4 | 失活回退 | 跟随中会话 ended/expired/失联 → 横幅提示后回独立操作（画面保留，沿用 display 语义） |
| D5 | 关闭=本次独立 | 关闭弹层不再弹出（本次页面生命周期内），本页保持独立计时不上报 |

**服务依赖**：零新增——`GET /api/display/:token/state`（探测/全量校准）、`GET …/stream`（SSE）、
`POST/PUT/DELETE session`（接管后复用）。

**Action 增量**：

| Action Key | 触发 | 行为 |
|-----------|------|------|
| session/chooseFollow | 发现弹层「跟随」或跟随胶囊 | 进入跟随态（hook 以 shareToken 走 follow 分支） |
| session/chooseTakeover | 弹层「接管」/跟随胶囊「接管」 | 采纳快照 + 续接上报（现 restore 原语） |
| session/dismissPrompt | 弹层关闭 | 本次生命周期内独立模式 |

**字典 Key 增量**（三语言）：

| Key | zh-Hans | en | fr-CA |

| timer.session.foundTitle | 检测到正在进行的遥控器会话 | Remote session detected | Session de télécommande détectée |

## 12. v1.5 增量：遥控指令通道（C-02-07，2026-10-12）

**背景**：架构探讨确认——手机作为计时主机存在后台节流硬伤（灭屏 → 定时器节流 → 计时
漂移 + 心跳停 + 会话 10s 判死）。双模方案：电脑主机 + 手机瘦遥控；无主机时手机回退
本地计时（离线 NFR 保留）。API 契约见 api-remote-command.md v1.0。

**设计决策**：

| # | 决策 | 内容 |
|---|------|------|
| D1 | 弹层三选 | 发现弹层改为 **遥控**（默认）/ 接管 / 取消；「跟随」由「遥控」取代（遥控端=看状态+可操作，纯只读跟随保留给 display 页） |
| D2 | 遥控模式 | 进入后复用 follow 基建订阅快照流（状态回流）；按钮（对切/巨主钮/重置/阶段横滑）改发 `POST session/command`；顶栏胶囊「遥控中」+ 失联提示 |
| D3 | 主机端消费 | 会话激活时经 display 流订阅 `command` 事件；commandSeq 单调去重后映射引擎动作 dispatch；与主机本地操作经同一 reducer 串行 |
| D4 | 指令确认 | 快照回流即确认（seq 变化）；无重试/回执 UI |
| D5 | 计时加固 | TICK 时间戳增量 + visibilitychange 重锚（catch-up 限幅 300s）；serverTime 钟偏校准激活——双端受益 |

**Action 增量**：

| Action Key | 触发 | 行为 | 对应接口 |
|-----------|------|------|---------|
| session/chooseRemote | 弹层「遥控」 | remoteMode=true + 订阅快照流 | —（复用 display stream） |
| remote/command | 遥控模式按钮 | 发指令 `{type: start/stop/reset/toggle, side}` 或 `{type: applyStage, stageId}`，失败提示失联回退本地 | POST #command |
| host/applyCommand | 主机端 command 事件 | seq 去重 → dispatch 引擎动作 | SSE `command` |

**字典 Key 增量**（三语言）：

| Key | zh-Hans | en | fr-CA |
|-----|---------|-----|-------|
| timer.session.remote | 遥控 | Remote | Télécommander |
| timer.session.remoteMode | 遥控中 | Remote control | Télécommande active |
| timer.session.remoteLost | 遥控失联，已回退本地计时 | Remote lost — local timing | Télécommande perdue — minuterie locale |
