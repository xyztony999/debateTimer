## 1. 业务目标与范围

### 1.1 业务目标（G1）

完成"手机遥控主程序"闭环：操作员在手机遥控器上开计时，**电脑打开主程序首页 `/` 即可
选择跟随**（实时镜像手机操作）或接管（电脑夺回控制权）。消除"电脑开首页与手机互不相干、
甚至互相抢会话"的困惑——这正是真机反馈"遥控器得跟主程序联动"的诉求。

### 1.2 功能范围（G2）

**做什么（FB-2 控制台跟随）**：
- 控制端页面（桌面控制台与手机遥控器布局均适用）在初始化探测到**本人活跃控制会话**
  时，弹层提示"检测到正在进行的遥控器会话"，提供两选：**跟随** / **接管**
  （跟随为默认焦点）
- 跟随模式：本页进入只读镜像——复用大屏跟随的快照采纳/插值/SSE 语义；保留本页布局
  （控制台或遥控器），但全部计时操作禁用；顶栏常显跟随胶囊（含"接管"入口）
- 接管模式：本页采纳当前快照并续接上报（即现有会话恢复行为）；原遥控端因快照序号
  冲突在心跳失败后自动退位为独立模式并提示"同步已结束"（≤4s，无需新通知通道）
- 跟随中会话失活（遥控端停止/超时）：跟随页横幅提示并回退独立操作（画面保留）
- 关闭弹层（暂不选择）＝维持独立模式（不上报、不跟随；与既有"页面刷新恢复会话"
  行为的差异：探测到活跃会话时不再静默接管，先询问）

**做什么（FB-1 间距修正）**：
- 遥控器布局：语境位（试铃按钮/自动推进横幅）与主操作区之间补间距；语境行与
  阶段名行间距同步理顺（现状 4px 贴死）

**不做什么**：
- 不新增任何 API/字段（复用 `GET /api/display/:token/state`、SSE、session 三接口）
- 不做跨账号会话发现（仅本人分享令牌）
- 不做双端同时控制的冲突合并（明确主从：一个会话同一时刻仅一个控制端上报）
- 不做"不再询问"偏好记忆（每次探测到都问，保持行为可预期）
- 不改大屏页（`/display/:token`）行为

## 2. 角色与对象（G3/G4/G5）

- **角色**：计时操作员（一人多设备：遥控端 + 跟随/接管端）
- **领域对象**：**零新增**。复用控制会话（ControlSession）与计时快照（TimerSnapshot）；
  新增过程数据仅 P3 UI 状态（跟随模式开关、角色选择弹层开合、跟随胶囊）。

## 3. 功能需求

### FR-1 会话发现与角色选择

- 控制端初始化（config 加载完成后）探测本人活跃会话（复用 restoreLiveSession 的
  loadDisplayState 通道）；探测到 active → 弹 MUI Dialog：
  - 文案：检测到正在进行的遥控器会话（当前模板名）；按钮：**跟随**（默认）/ 接管 / 关闭
- 三种选择的终态：跟随 → follow 模式；接管 → 现有 restore 行为；关闭 → 独立模式（本次会话内不再弹）

### FR-2 跟随模式

- 快照采纳/SSE 订阅/本地插值/弱信号提示：复用 display 侧既有实现（hook 以
  shareToken 运行 follow 分支）
- 只读化：TimerBox 操作钮/遥控器主钮禁用 + 跟随提示文案；阶段时间线禁用；
  顶栏跟随胶囊（"正在跟随遥控器"）+「接管」按钮
- 会话失活 → 横幅"遥控器会话已结束"→ 回独立模式
- 跟随模式下开启"大屏同步"入口隐藏（本页已是跟随端，不能又当控制端）

### FR-3 接管

- 点击接管（弹层内或跟随胶囊中）：采纳快照、续接上报（现有 restore 原语），
  弹层关闭、胶囊转"大屏同步中"
- 原遥控端：上报 seq 冲突 → 400 → 判定会话结束 → 自动保存记录并回独立模式（既有行为）

### FR-4 遥控器间距修正（FB-1）

- `.rm-main` 与语境位之间 ≥12px；语境行与阶段名间距统一（12px）；不影响控制台布局

## 4. 非功能需求

- 跟随端交互延迟：操作发生 → 跟随端呈现 ≤1s（沿用大屏 NFR-1）
- 探测不增加首屏阻塞（异步探测，弹层出现不打断本地计时可用性）
- 竖屏遥控器布局的跟随态同样只读（两布局共用 follow 状态）

## 5. 验收标准

1. 手机开会话并操作 → 电脑开 `/` → 弹层出现 → 选跟随：电脑端控制台布局实时镜像
   （阶段/时钟/宽限/锁死 ≤1s 跟上），操作全部禁用，胶囊含接管入口
2. 跟随中点接管 → 电脑成为控制端续操作；手机 ≤4s 内提示"同步已结束"回独立模式
3. 手机停会话 → 电脑跟随页横幅提示并恢复可操作
4. 遥控器布局（竖屏）同样完成 1-3；旋转切换布局时跟随态保持
5. 测试声音阶段：语境按钮与主钮间距 ≥12px（375px 视口实测）
6. lint / bun test / build 全绿；87 测试零回归
