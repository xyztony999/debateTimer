# PRD — 真机反馈包 R3：数字配对码 + 音频首载提速 + 单钟区分

| 属性 | 值 |
|------|-----|
| 版本 | v1.0 |
| 日期 | 2026-10-14 |
| 模块 | C-02-01 扩展（配对码）；C-01-05 附带（音频）；C-01-08 修正（单钟） |
| 关联 D0 | 用户确认：FB-A mp3 转码 / FB-B 数字配对码 / FB-C 单计时单钟 |

## 1. 范围

**做什么**：
- **FB-B 数字配对码**：开启远程控制后电脑顶栏显示 4 位配对码；手机 ☰ 菜单新增「连接电脑」
  → 输入配对码 → 服务端按 配对码+owner 匹配活跃会话 → 返回 configName/shareToken →
  手机直接进入遥控模式（支持跨配置：手机当前页面配置≠电脑配置也能连）
- **FB-A 音频提速**：四个提示音 WAV（~500KB，跨国下载 2-3s）转 MP3 单声道 64kbps
  （~60KB，8 倍提速）；warmupSounds 预载保留
- **FB-C 单钟区分**：遥控器布局双钟条在 single 模式阶段只显示一格钟（居中）；
  double/free 保持双钟

**不做什么**：配对码过期/轮换（会话结束即失效）；频率限制（owner 匹配使爆破无意义）；
扫码配对；音频 Web Audio 缓冲层

## 2. API 增量（api-pairing）

- 会话对象加 `pairingCode`（create 时随机 4 位数字字符串）
- `POST /api/session/pair` {code} [requireAuth]：活跃会话中找
  `pairingCode===code && ownerId===user.id` → `{ configName, shareToken }`；
  未匹配 → 业务失败
- 电脑端配对码经既有 `POST session` 响应带出（`pairingCode` 字段）

## 3. 验收

1. 电脑开会话 → 顶栏显示配对码；手机菜单「连接电脑」输入 → 秒进遥控模式（跨配置场景成立）
2. 错码/他人会话码 → 明确失败提示；会话结束后配对码失效
3. 提示音首载：清缓存后页面加载 → 点试铃 <1s 出声（原 2-3s）
4. 单计时阶段（一辩陈词）手机只显示一格钟；自由辩论双钟
5. 101+ tests 全绿
