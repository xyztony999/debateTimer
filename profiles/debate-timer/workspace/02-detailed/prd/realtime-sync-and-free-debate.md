## 1. 背景与目标

### 1.1 解决什么问题

现状：分享出去的大屏链接（`/display/:token`）是一个匿名独立计时页，只随配置变更同步模板
（SSE 仅广播配置变化）。比赛现场仍需在投影那台设备上操作计时——「一人操作、多屏观看」
的诉求不存在。同时，自由辩论环节需要主席手动启停双方计时，操作频繁易错。

### 1.2 为谁提供价值

- **计时操作员（主席/计时员）**：在自己的手机/笔记本上完成全部计时操作
- **观众/辩手/评委**：投影大屏实时跟随当前环节与剩余时间
- **赛事组织（UOMDC）**：自由辩论计时符合赛制惯例（停一方即起对方）

### 1.3 业务目标

1. 大屏跟随延迟感知 ≤ 1 秒（亚秒级插值）
2. 自由辩论环节主席每轮操作从 2 次点击降为 1 次
3. 不破坏既有使用方式：无会话时分享页行为与现状一致

## 2. 角色与用户故事

| 角色 | 用户故事 |
|------|---------|
| 计时操作员 | 作为主席，我要在手机上启停计时，让大屏同步显示，这样我可以在场地任何位置控场 |
| 计时操作员 | 作为主席，我要知道控制会话是否正常（连接状态），避免比赛白计时 |
| 计时操作员 | 作为主席，在自由辩论里我停掉正方时反方要自动开始计时，减少操作 |
| 观众 | 作为观众，大屏要一直显示当前环节和倒计时，网络抖动时不能跳变或卡死 |
| 观众 | 大屏要和主席的操作同时发出 30 秒提醒和到时铃声 |

## 3. 功能范围

### 3.1 做什么

1. **控制会话**：操作员基于当前模板开启/结束会话；会话即状态同步作用域
2. **状态快照上报**：计时状态变化即上报 + 2 秒心跳；快照带服务器时间戳与单调序号
3. **大屏跟随**：会话活跃期显示端只读渲染，按时间戳本地插值；告警（声/闪）同步
4. **断线恢复**：重连先拉全量快照；会话失活（心跳超时/分享停用）显示端提示并回退独立模式
5. **自由辩论**：阶段计时模式新增「自由辩论」；停止一方自动启动对方；一方到时自动切换；
   双方到时环节结束
6. **兼容降级**：旧客户端读到 `free` 模式按双计时处理

### 3.2 不做什么

- 不做服务端权威计时（服务端不 tick，只中转与缓存）
- 不做多人协同编辑/多控制端互斥（last-writer-wins，见 BR-7）
- 不做计时历史存档/回放（赛后复盘属后续迭代）
- 不做显示端反向操作（跟随模式严格只读）
- 不做 WebSocket 通道（沿用 SSE）
- 控制会话不做持久化（服务重启即失效，回退独立模式）

## 4. 功能需求详述

### FR-1 控制会话管理（C-02-01）

- 操作员在计时页对当前配置「开启控制会话」；要求配置已启用分享（否则引导去开启）
- 开启成功返回会话标识与该配置的分享令牌；操作员可一键复制大屏链接
- 操作员可主动「结束会话」；结束即向大屏广播会话结束事件
- 失活条件（任一）：操作员主动结束；心跳超时（> 10 秒无快照）；分享被停用/令牌轮换；
  服务进程重启
- 会话失活后，新开 会话可直接重建（同名配置同时至多一个活跃会话，后者覆盖前者）

### FR-2 计时状态上报（C-02-02）

- 控制端在下列时机上报：启停/重置/阶段切换/自由辩论自动切换/会话开启（初始快照）
- 另每 2 秒心跳上报一次当前快照（兼作失活保活）
- 快照字段见 §6.1；seq 在会话内单调递增，服务端拒绝回退序号

### FR-3 大屏跟随展示（C-02-03）

- 显示端加载：先 GET 配置（既有）再 GET 状态快照；有活跃会话 → 进入跟随模式
- 跟随模式渲染：当前阶段（含多语言名称）、单/双/自由辩论布局、双方剩余时间、活跃阵营
- 时间插值：以快照 `serverTime` 与本机时钟估算钟偏，本地逐秒递减；新快照到达即校准
- 只读守卫：跟随模式隐藏全部计时操作入口与快捷键绑定
- 告警同步：剩余 30 秒与到时的闪烁/提示音按本地插值时间触发，表现与控制端一致

### FR-4 断线恢复（C-02-04）

- SSE 断线自动重连（浏览器原生 EventSource 行为）；重连后先 GET 最新快照再续订
- 收到会话结束/失活事件 → 显示「会话已结束」提示并回退独立模式（保留当前阶段数据）
- 快照静默缺失 > 5 秒（心跳周期 + 容忍）→ 显示端标注「信号弱」，继续按最后快照插值

### FR-5 自由辩论计时控制（C-01-03）

- 阶段计时模式枚举扩展：`single` / `double` / `free`（设置页阶段编辑新增选项；多语言文案齐备）
- `free` 模式交互：
  - 初始：双方均就绪（沿用双计时布局）
  - 显式停止一方（点击/快捷键 A 或 L）→ 立即自动启动对方
  - 一方剩余时间到 0 → 自动切换至对方（若对方有时间剩余）；铃声提示
  - 双方均为 0 → 环节结束（双双锁定，显示环节结束态）
  - 重置（Shift+Q / Shift+O / 整体重置）→ 恢复常规双计时操作（自动切换暂停生效直至再次显式切换）
- 快照以 `free` 模式上报，显示端按自由辩论布局渲染并高亮当前发言方

### FR-6 兼容与降级（S-01-02 / C-01-03）

- 配置 schema：`timerSettings` 值域扩展 `free`；旧数据无感知（缺省值不变）
- 旧客户端遇到 `free`：按 `double` 渲染与操作（不崩溃、不丢数据）
- 未升级的显示端收到 `free` 快照：同上降级

## 6. 领域对象与数据

### 6.1 计时状态快照（值对象，不可变）

| 字段 | 类型 | 说明 |
|------|------|------|
| seq | int | 会话内单调递增序号 |
| stageId | string | 当前阶段标识 |
| stageMode | enum | `single` / `double` / `free` |
| remainingAffMs | int | 正方剩余毫秒（单计时亦存此字段） |
| remainingNegMs | int | 反方剩余毫秒（单计时时等于 aff） |
| runningAff | bool | 正方计时中 |
| runningNeg | bool | 反方计时中 |
| activeSide | enum | `aff` / `neg` / `none`（当前发言方，自由辩论用） |
| serverTime | long | 服务器时间戳（ms，钟偏校准） |

### 6.2 控制会话（聚合根，内存态）

| 字段 | 类型 | 说明 |
|------|------|------|
| sessionId | string | 服务端生成 |
| configId / configName | id / string | 绑定配置 |
| shareToken | string | 寻址键（冗余自配置） |
| ownerId | id | 归属人 |
| status | enum | `active` / `ended` / `expired` |
| startedAt / lastSeenAt | timestamp | 开启与最近心跳 |
| lastSnapshot | 快照 | 最新缓存（供新订阅者即时下发） |

### 6.3 对象关系

控制会话 1 ── 1 配置文档（N:1 跨域引用，仅存 configId）；控制会话 1 ── N 快照（仅保留最新，
历史不存）；快照隶属会话，随会话失效。

## 7. 状态流转

### 7.1 控制会话状态机

```
[不存在] --开启(owner)--> active --主动结束--> ended
                          active --心跳超时>10s / 分享停用 / 进程重启--> expired
ended/expired --再次开启(新会话)--> active（新 sessionId，旧会话被覆盖）
```

### 7.2 自由辩论环节内行为状态（前端本地）

```
idle(双方停) --启动A--> A 发言 --停A--> 自动 B 发言 --停B--> 自动 A 发言
A 或 B 剩余=0 --> 自动切换对方；双方均=0 --> locked(环节结束)
任意 reset --> 回到 idle（自动切换挂起，直至下次显式启动）
```

## 8. 业务规则

| # | 规则 |
|---|------|
| BR-1 | 仅配置 owner 可开启/结束会话与上报快照；写操作走既有 cookie 会话 + CSRF |
| BR-2 | 会话寻址键 = 配置当前有效 shareToken；分享停用/令牌轮换即判失活 |
| BR-3 | 快照 seq 会话内单调递增；服务端拒绝 seq ≤ 缓存序号的上报（幂等去重） |
| BR-4 | 同一配置同时至多一个活跃会话；重复开启覆盖旧会话并广播其结束 |
| BR-5 | 显示端在会话活跃期严格只读：无操作按钮、无快捷键副作用 |
| BR-6 | 显示端插值不得早于最新快照时间轴（只校准、不回拨）；剩余时间下限 0 |
| BR-7 | 多控制端不做互斥：seq 大者胜（last-writer-wins） |
| BR-8 | 自由辩论：显式停止一方 ⇒ 对方自动启动；一方到 0 ⇒ 切换对方；双 0 ⇒ 锁定 |
| BR-9 | 重置操作中止自动切换链，恢复手动双计时，直至下一次显式启动 |
| BR-10 | 旧客户端遇 `free` 一律按 `double` 降级，不得报错或丢配置 |

## 9. 非功能性要求

| # | 要求 |
|---|------|
| NFR-1 | 端到端跟随延迟：操作发生 → 大屏呈现 ≤ 1s（局域网/正常公网） |
| NFR-2 | 心跳 2s；失活判定阈值 10s；显示端「信号弱」阈值 5s |
| NFR-3 | 单服务进程并发活跃会话 ≤ 100（内存态，超出拒绝并提示） |
| NFR-4 | SSE 断线期间显示端连续插值，恢复后 ≤ 1 次全量校准 |
| NFR-5 | 快照单条 ≤ 1KB；广播扇出按 token 定向（复用 sseHub 作用域） |

## 10. 异常场景

| 场景 | 处理 |
|------|------|
| 控制端刷新页面 | 会话仍活跃（服务端缓存）→ 前端重连后拉取快照续操作 |
| 控制端断网 > 10s | 会话 expired，大屏提示并回退独立模式 |
| 服务重启 | 全部会话丢失（内存态）→ 大屏超时后回退独立模式 |
| 大屏时钟不准 | 以 serverTime 钟偏校准，不信任本机绝对时间 |
| 上报乱序/重复 | seq 校验拒绝（BR-3） |
| 分享在会话中被停用 | 会话判失活，大屏回退独立模式但保留最后画面数据 |

## 11. 验收标准

1. 手机开控制会话、电脑开大屏：操作启停/切阶段，大屏 ≤1s 跟随；拔线 30s 再插，自动恢复
2. 30 秒提醒与到时铃声在控制端与大屏同时触发
3. 自由辩论：停正方反方自动走表；一方到零自动切换；双零锁定；重置后恢复手动
4. 旧版本前端打开含 `free` 阶段的配置不报错，按双计时可用
5. 无会话时，分享页与当前线上行为一致（回归）
6. 非本人配置调用会话/上报接口返回 403
