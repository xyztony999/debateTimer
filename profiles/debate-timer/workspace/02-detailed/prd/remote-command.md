## 1. 业务目标与范围

### 1.1 业务目标（G1）

消除「手机作为计时主机」的后台节流硬伤（灭屏 → 定时器节流 → 计时漂移 + 心跳停 +
会话 10s 判死）：比赛计时权威移到**电脑主机**，手机遥控器降级为瘦指令端——灭屏/切后台
对计时零影响；同时保留手机独立计时能力（无主机/断网场景，PRD 承诺不回退）。

### 1.2 功能范围（G2）

**做什么**：
- 发现弹层（C-02-06）扩为三选：**遥控**（默认，发指令+状态回流）/ 接管 / 取消；「跟随」
  语义由「遥控」取代（遥控端既看状态又可操作，纯只读跟随保留给 display 页）
- 遥控模式：遥控器布局的按钮（对切/巨主钮/重置/阶段横滑）从本地 dispatch 改为
  `POST session/command`；状态经既有快照流实时回流（复用 follow 订阅）；连接态胶囊
- 主机端：会话激活时经 display 流订阅 `command` 事件，commandSeq 去重后映射引擎动作
- 计时健壮性加固（随包）：TICK 改时间戳增量 + visibilitychange 重锚（灭屏回来追平
  真实流逝时间，catch-up 限幅 300s 防 runaway）；serverTime 钟偏校准激活（快照插值）

**不做什么**：
- 不拆遥控器独立 bundle（引擎 22KB vs 共享层 551KB，无收益）
- 不修订离线 PRD（无主机时手机回退本地计时，断网能力不变）
- 不做多遥控器并发仲裁（单遥控器；队列保序，指令到达主机端串行执行）
- 不做指令重试/回执 UI（快照回流即确认；失联胶囊提示重连）

### 1.3 决策记录

| # | 决策 | 依据 |
|---|------|------|
| RC-1 | 双模：有主机连主机（发指令），无主机本地计时 | 探讨确认（离线 NFR 保留 + 节流硬伤消除） |
| RC-2 | 指令确认 = 快照回流 | 零新 ack 通道；seq 变化天然反馈 |

## 2. 角色与对象

- 角色：计时操作员（一人双设备：主机端 + 遥控端）
- 领域对象：零新增聚合根。控制会话扩展过程属性（指令队列/序号）；指令 RemoteCommand
  为过程数据（P5 集成载荷）；快照/引擎对象全部复用。

## 3. 功能需求

### FR-1 遥控模式进入与退出

- 发现弹层选「遥控」→ 进入遥控模式：清 pendingSession、以 config.shareToken 建立快照流
  订阅（复用 follow 基建）+ `remoteMode=true`
- 遥控模式下顶栏胶囊「遥控中」；会话失活 → 提示并回退本地计时（引擎状态保留）
- 遥控模式下「接管」入口保留（遥控端→主机反转，语义同 C-02-06）

### FR-2 指令发送

- 按钮映射：对切钮/巨主钮/重置/阶段横滑 → `{type, side?, stageId?}` POST command
- 发送失败（404 会话没了/网络断）→ 胶囊失联态 + 提示；指令不重试
- 键盘快捷键在遥控模式下禁用（enabled = !following && !remoteMode）

### FR-3 主机端指令执行

- 会话激活（sessionState active/weak）时订阅 display 流的 `command` 事件
- commandSeq 单调去重（≤已执行序号的丢弃）；映射引擎动作 dispatch；主机本地操作与
  指令经同一 reducer 天然串行
- 主机端 UI 不变（桌面控制台；被遥控操作的按钮态随引擎状态自然变化）

### FR-4 计时健壮性（双端受益）

- 引擎 TICK 由"每次 -1"改为"按 lastTickAt 时间戳差值补秒"（interval 仍 1s 触发，
  每次按真实流逝补齐；visibilitychange visible 时立即重锚触发一次）
- catch-up 限幅：单次补秒 ≤300s（超限按 300s 处理，防时钟被改/runaway）
- serverTime 钟偏：adoptFromSnapshot 时记录 `clockOffset = serverTime - Date.now()`，
  显示端插值以 offset 校准（轻量，修正 NFR-4 的遗留实现缺口）

## 4. 非功能需求

- 指令端到端：遥控按钮 → 主机执行 → 大屏呈现 ≤1s（网络正常）
- 队列上限 32 / 会话（D-4）；遥控器失联提示 ≤5s（复用弱信号判定）
- 离线：遥控器断网回退本地计时（横幅提示），恢复后可重新进入遥控模式

## 5. 验收标准

1. 三标签（主机电脑/遥控手机竖屏/大屏）：遥控点对切 → 主机引擎执行 → 大屏 ≤1s 换边；
   遥控端自身状态回流正确
2. 遥控标签后台节流模拟（visibility hidden ≥30s）：主机计时不受影响；遥控回前台状态追平
3. 主机本地操作与遥控指令并发：无冲突（引擎串行）
4. 会话结束：遥控端提示并回退本地计时；引擎状态保留
5. TICK 加固：模拟 60s 节流后恢复，时钟追平真实时间（±1s）；单测覆盖 catch-up 限幅
6. lint / bun test / build 全绿；零回归
