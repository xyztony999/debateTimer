## 1. 业务目标与范围

### 1.1 业务目标（G1）

操作员在比赛现场用**手机单手**完成全部计时控场（方向 1 遥控器场景的落地）：
电脑/投影开大屏（`/display/:token`），手机开控制端即遥控器——换边、启停、
切环节全部拇指可达，无需精准点按小按钮，不看手机也能完成主操作。

### 1.2 功能范围（G2）

**做什么**：
- 手机竖屏（视口宽 ≤600px 且 orientation: portrait）下，控制端（`/`）自动呈现遥控器布局
- 单计时环节：缩小双钟置顶 + 单个巨型 播放/暂停 切换主钮 + 次级重置钮
- 双计时环节：缩小双钟置顶 + 当前环节各侧启停（对切仅自由辩论）
- 自由辩论环节：双大钮对切——两个半屏大钮「正方发言 / 反方发言」，点击**正在发言方**
  = 停止该方并自动启动对方（一键换边）；当前发言方高亮
- 阶段横滑条保留（切环节高频操作），同步状态胶囊常显顶栏
- 其余工具（设置/记录/保存记录/复制大屏链接/结束同步/语言/主题/登出/安装）收纳进 ☰ 菜单
- sound_check 试铃按钮跟随阶段语境显示；自动推进倒计时横幅保留
- 宽限（收尾中橙显）/锁死（红闪）/自由辩论锁态/信号弱——全部沿用既有状态呈现语义，仅重排

**不做什么**：
- 不新增任何 API、字段、领域对象（纯呈现层）
- 不做布局手动切换开关（竖屏自动，横屏/桌面自动回落控制台布局）
- 不做遥控器专用路由/入口
- 不做大屏端（viewer）的任何变更
- 不做 iOS 音频解锁策略调整（独立议题）
- 桌面控制台布局与快捷键行为不变

### 1.3 D0 决策记录

| 决策 | 内容 | 依据 |
|------|------|------|
| R-C1 触发 | 竖屏（≤600px + portrait）自动切换，无手动开关 | 场景即布局，零操作成本（D0 确认） |
| R-C2 自由辩论主操作 | 双大钮对切：点当前发言方 = 停止 + 自动切对方 | 单手最快路径（D0 确认） |
| R-C3 单计时形态 | 巨型播放/暂停主钮 + 缩小双钟置顶 + 次级重置 | 单一主目标降低误触（D0 确认） |
| R-C4 工具收纳 | 阶段横滑 + 同步胶囊常显；其余进 ☰ 菜单 | 高频保留低频收纳（D0 确认） |

## 2. 角色与对象（G3/G4/G5）

- **角色**：计时操作员（唯一交互者；复用既有认证与会话能力）
- **领域对象**：**零新增**。遥控器布局是 C-01/C-02 既有领域对象
  （计时状态机、控制会话、快照）的呈现形态。D2-2 判定：无聚合根/实体/
  值对象/子流程/关联领域对象变更；涉及的过程数据仅 P2 展示数据
  （对切按钮态、布局触发态）与 P3 UI 交互状态（菜单开合）。

## 3. 功能需求

### FR-1 布局触发与回落

- 视口宽 ≤600px 且 `orientation: portrait` → 遥控器布局；其余（横屏、桌面、平板竖屏 >600px）→ 控制台布局
- 旋转设备即时切换，布局状态不持久化（每次按当前视口判定）
- 与暗色/浅色、三语言、PWA standalone 完全正交

### FR-2 单计时遥控形态（single 模式阶段）

- 顶栏：🎯 标题（xs 截断）+ 同步状态胶囊 + ☰ 菜单
- 双钟条：正/反方剩余时间并排小钟（队名+徽标，当前阶段仅显示不操作对方），
  宽限中橙显、锁死红闪沿用
- 主区：巨型 播动/暂停 切换主钮（高度 ≥ 屏高 30%，全宽），点击即 toggle
- 次级钮：重置（主钮下方，次级视觉）
- 阶段横滑条位于主钮下方（拇指区）

### FR-3 双计时遥控形态（double 模式阶段）

- 同 FR-2 骨架；主区为两侧启停钮（各半屏）+ 各侧重置次级钮；
  按钮态显示运行中/已停止

### FR-4 自由辩论遥控形态（free 模式阶段）

- 主区两个半屏大钮：「▶ 正方发言」「▶ 反方发言」（含队名）
- **对切语义**：点击正在发言方的钮 = STOP 该方（引擎自动启动对方）；
  点击未发言方的钮 = START 该方（引擎原生支持，等价桌面 A/L 切换）
- 当前发言方钮高亮（描边/填充），双方耗尽 → 两钮置灰 + 环节已结束文案 + 重置入口
- 30s 提醒/宽限/锁死在对应方的**双钟条小钟**上呈现（主钮不承载时间信息，避免误读）

### FR-5 状态与反馈映射

| 既有状态 | 遥控器呈现 |
|---------|-----------|
| 同步 active/weak | 顶栏胶囊绿/橙（常显）；开启/停止/复制链接在 ☰ 菜单 |
| 自动推进倒计时 | 主区顶部横幅（点任意主钮即取消，沿用引擎语义） |
| sound_check | 试铃双钮显示于主区上方语境位 |
| 保存记录 | ☰ 菜单内（captureCount>0 才可用）；会话结束自动保存不变 |
| 会话通知（Snackbar） | 顶部浮层，4s 自动消失（沿用） |

## 4. 非功能需求（N1-N3）

- **触达区**：主钮 ≥88px 高；横滑条阶段钮 ≥44px；全部拇指可达（下半屏）
- **防误触**：主操作单一目标化（R-C3）；重置为次级视觉不与主钮同行
- **性能**：布局切换纯 CSS/条件渲染，不引入新依赖；不增加包体（复用 MUI + 既有组件）
- **离线**：遥控器布局在 PWA 离线壳内同样可用（无网络依赖差异）

## 5. 验收标准

1. 375×667 视口：单计时/双计时/自由辩论三形态正确渲染，主钮触达区达标
2. 自由辩论对切：点当前发言方大钮，发言权 1 秒内换边且双钟同步
3. 竖屏转横屏：即时回落控制台布局，计时状态无损
4. 遥控器模式下开同步会话 → 大屏跟随与桌面形态完全一致（快照协议无感知）
5. 暗色/浅色、中/英/法加在遥控器布局下均正常
6. lint / bun test / build 全绿；现有 87 测试零回归
