# PRD — 模板广场（迭代包 C）

| 属性 | 值 |

## 1. 背景与目标

新用户第一件事是配赛制——现在只能手工搭。把社区验证过的赛制（UOMDC、BP、奥瑞冈等）沉淀为
公开模板，一键复制即用。目标：新用户从注册到可开赛 ≤ 1 分钟。

## 2. 角色与用户故事

| 角色 | 故事 |
|------|------|
| 新用户 | 打开模板广场，看各赛制的阶段构成，一键复制成我的模板 |
| 老用户 | 把调好的赛制发布到广场回馈社区；随时可取消 |
| 匿名访客 | 不登录也能浏览广场（复制时引导登录） |
| 管理员 | 下架违规模板（不动归属人数据） |

## 3. 功能范围

### 3.1 做什么

1. **发布管理（FR-C1）**：设置页模板管理卡新增「发布到广场」开关（owner）；
   `POST /api/configurations/:name/visibility {public}`
2. **广场浏览（FR-C2）**：`GET /api/gallery`（匿名，游标分页，更新时间降序）+
   `GET /api/gallery/:id`（只读投影，复用 toDisplayResponse + 摘要）；**不返回 ownerId**
3. **模板复制（FR-C3）**：广场详情页「复制到我的模板」→ 默认名「源名 (副本)」→
   经既有 saveConfiguration 落库；未登录跳登录页
4. **违规下架（FR-C4）**：`POST /api/gallery/:id/unpublish`（admin）
5. **预置赛制（FR-C5）**：导入脚本支持 `--public`，官方账号预置 UOMDC/BP/奥瑞冈等

### 3.2 不做什么

- 不做搜索/分类/评分/评论（后续迭代，C-C7）
- 不做贡献者署名（隐私，C-C2）
- 不做广场模板直接使用（必须先复制——避免「用了别人的」心智）
- 不做版本管理/更新通知（复制即分叉，C-C3）

## 4. 功能需求详述

### FR-C1 发布管理
- 开关位于设置页「模板管理」卡；发布 = `isPublic:true` + updatedAt 刷新；取消即时下架
- 删除模板即天然下架；改名不影响发布状态
- 默认模板（UOMDC）服务端 seed 为公开

### FR-C2 广场浏览
- 列表项：`{id, name, stageCount, totalSeconds, modeSummary, updatedAt}`；
  modeSummary 如 `single×12 · double×3 · free×1`
- 详情：阶段清单（名称多语言按请求语言解析最佳匹配）+ 全部配置字段（只读）
- 路由 `/gallery` 公开（同 /display 免登录）

### FR-C3 模板复制
- 详情页按钮；已登录：预填名「源名 (副本)」可改 → 保存 → 跳设置页加载新模板
- 未登录：跳 `/login?next=/gallery/:id`

### FR-C4 违规下架（admin 页入口，后续可在管理页扩展；本包提供 API + 管理页最小按钮）

### FR-C5 预置赛制
- `import-configurations.js --public`：导入同时置 isPublic；赛制 JSON 放
  `server/scripts/presets/`（本包附 UOMDC 现行默认 + BP + 奥瑞冈三份样例）

## 5. 角色权限

| 操作 | 操作员 | 匿名 | 管理员 |
|------|--------|------|--------|
| 发布/取消（本人模板） | ✓ | ✗ | ✗ |
| 浏览广场 | ✓ | ✓ | ✓ |
| 复制 | ✓ | 引导登录 | ✓ |
| 强制下架 | ✗ | ✗ | ✓ |

## 6. 领域对象与数据（增量）

| 对象 | 变更 |
|------|------|
| 配置文档 | +`isPublic`（bool，缺省 false）；索引 `{isPublic:1, updatedAt:-1}`（partial） |
| 广场列表项 | 过程数据（P2 展示派生：stageCount/totalSeconds/modeSummary 由文档派生，不落库） |

无新聚合根；模板广场=配置文档的公开性横切视图。

## 7. 状态流转

`isPublic: false ⇄ true`（owner 开关；admin 单向置 false）。无其他状态。

## 8. 业务规则

| # | 规则 |
|---|------|
| CB-1 | 广场列表/详情响应不包含 ownerId/username/shareToken |
| CB-2 | 只能发布本人模板（403）；默认模板可被 owner（首个管理员）发布/取消 |
| CB-3 | 复制名在本人模板空间内唯一（复用保存端点约束）；冲突提示改名 |
| CB-4 | 广场详情不暴露 shareToken（公开模板不需要分享令牌即可读） |
| CB-5 | 分页 limit ≤50，默认 20 |

## 9. 非功能性

公开读接口无认证：限流沿用部署层（无应用层限流，记 NFR 债务）；列表查询走 partial index。

## 10. 异常场景

| 场景 | 处理 |
|------|------|
| 复制时源被取消发布 | 保存端点返回源读取 404 → 提示「模板已下架」 |
| 广场为空 | 引导文案 + 提示管理员可导入预置赛制 |
| 发布模板随后被改成私密内容再公开 | 以最新内容呈现（无审核流程，记 WARN） |

## 11. 验收标准

1. 发布模板 → 匿名浏览器打开 /gallery 可见，详情不出现任何用户身份信息
2. 一键复制 → 我的模板列表出现「X (副本)」，可加载编辑，与源一致
3. 取消发布/删除模板 → 广场即时不可见；强制下架同理
4. `--public` 导入三份预置赛制 → 广场出现三项
5. 非本人调用 visibility 403；匿名调用 publish 401
6. 回归：私有模板不出现在广场；分享功能不受影响
