# D0 需求澄清报告 — 迭代包 B：比赛记录与复盘

| 属性 | 值 |
|------|-----|
| 日期 | 2026-10-11 |
| 输入 | 比赛日志：记录每阶段实际用时、超时次数，赛后导出（与登录态/模板 API 天然集成） |
| 运行模式 | 增量（三文档 v1.1 → v1.2） |

## 0.1 业务概念

| 维度 | 提取 |
|------|------|
| 术语 | 比赛记录（MatchRecord）、阶段实绩（per-stage actuals）、超时（overrun，主时间+宽限尽仍未停）、复盘、导出（CSV/JSON） |
| 角色 | 计时操作员（采集与复盘）、管理员（代管查看） |
| 流程 | 计时操作 → 阶段实绩本地累计 → 会话结束/手动保存 → 提交记录 → 列表/详情复盘 → 导出/删除 |
| 规则 | 记录按 owner 隔离；阶段实绩含计划/实际对比与超时标记；记录不可编辑（只读+删除） |
| 数据 | MatchRecord：模板快照（名称/队名/阶段定义）+ 每阶段 {计划秒/实绩秒(正反)/超时标记/起止} + 比赛起止 |

## 0.2 匹配

无匹配（全新能力）——但复用：owner 隔离中间件、模板域字段快照、登录态。控制会话结束事件（session ended）是自然的保存触发点。

## 0.3 类型

新增（新聚合根 + 新集合 + 新页面）→ D1 变更管理（BA 入口）+ 全套 D2/D3/D4。

## 0.4 决策

| # | 决策 |
|---|------|
| B-C1 | 采集在控制端本地累计（阶段进入/离开时间戳 + 运行秒数），**会话结束或手动「保存记录」时一次性提交**——不做服务端高频写入 |
| B-C2 | 超时定义：主时间+宽限耗尽（locked）即记一次超时（正/反分计；单计时计为正方） |
| B-C3 | 记录不可编辑：只读详情 + 删除；防篡改优先于修正便利 |
| B-C4 | 导出格式：CSV（表格复盘）与 JSON（原始数据）；文件名含比赛日期与模板名 |
| B-C5 | 模板字段以**快照**方式入记录（队名/阶段名/时长），赛后改模板不影响历史记录 |
| B-C6 | 保存失败不阻塞比赛（提示可重试，本地暂存最近一条待提交） |
| B-C7 | 匿名独立模式的计时不产生记录（无归属人）；跟随/控制模式才记录 |
