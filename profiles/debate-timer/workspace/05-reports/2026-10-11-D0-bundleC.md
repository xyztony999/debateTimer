| 运行模式 | 增量（三文档 v1.2 → v1.3） |

## 0.1 业务概念

| 维度 | 提取 |
|------|------|
| 术语 | 公开模板（isPublic）、模板广场（gallery）、发布/取消发布、复制到我的模板、预置赛制（seed） |
| 角色 | 认证用户（浏览/复制/发布自己的）、匿名访客（仅浏览，复制引导登录）、管理员（下架违规模板） |
| 流程 | owner 发布模板 → 进入广场列表 → 任意访客浏览详情 → 登录用户一键复制为本人模板 → 编辑使用 |
| 规则 | 广场匿名可读但**不泄露归属人身份**；复制产生独立副本（与源无关联）；取消发布立即下架；管理员可强制下架 |
| 数据 | 配置文档 +`isPublic`（bool）；广场列表项：模板名/阶段数/总时长/模式构成/更新时间 |

## 0.2 匹配

部分匹配 S-01 流程模板管理：CRUD/分享/导入既有；公开可见性与复制流程为新增。复用：saveConfiguration（复制落库）、toDisplayResponse（广场详情投影）、导入脚本（预置源）。

## 0.3 类型

增强 + 新增访问面（匿名广场）→ D1 变更管理（BA 入口，新 L3 模板广场管理）。

## 0.4 决策

| # | 决策 |
|---|------|
| C-C1 | 广场=配置文档 `isPublic` 标志的横切视图，不建新集合；索引 `{isPublic:1, updatedAt:-1}`（partial） |
| C-C2 | 匿名可浏览；**列表与详情不返回 ownerId/用户名**（隐私），贡献者匿名呈现 |
| C-C3 | 复制=前端读广场详情 → 以本人名义 `saveConfiguration(新名)`（既有端点），默认名 `源名 (副本)`；无服务端复制端点 |
| C-C4 | 发布/取消在设置页模板管理卡（owner）；删除模板时若已发布则同步下架（删除即消失，天然成立） |
| C-C5 | 管理员下架：`POST /api/gallery/:id/unpublish`（admin） |
| C-C6 | 预置赛制经既有导入脚本灌入官方账号并标 public（脚本加 `--public` 与目录约定），不在本包硬编码 |
| C-C7 | 广场列表按更新时间降序，游标分页；不提供搜索/分类（后续迭代） |
