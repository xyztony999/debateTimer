## 过程记录（新坑入档）

- **IAB 过渡冻结**：evaluate 派发点击后立即读计算样式，读到的是**冻结在过渡起点的值**
  （IAB 节流不给动画 tick，`transition: background-color .2s` 永不推进），一度误判
  "已过/当前样式互换"。以 `getAnimations()` 证实过渡挂起；解法：断言前注入
  `transition: none !important` 测试钩子（类切换即时生效）。后续 IAB 样式断言均须如此。
- CSS 规则序：同特异性下 `.st-step--interchange .st-name`(600) 会盖掉
  `.st-step--current .st-name`(700)，已把 interchange 规则排到 current 之前。
- 低分辨率截图对视觉模型仍不可靠（本次七项问法收敛后可用），计算样式断言为准。

## 回归修复（上线后用户反馈）

**用户报告**：第 2 站左侧有明显空隙，其它站没有（附截图）。

**根因（DOM 实测证实）**：点距完全均匀（72px 步距），但**线带覆盖有 36px 的洞**——
v2 D6 加"首站左 stub"时 `.st-step:first-child::after { left: 0 }` 只把段左移了半步、
宽度仍继承 100%：首站段覆盖 [左缘, 自身中心+半步]，而次站段从**次站中心**起画，
两段之间 [138, 174] 无线。v1 无 first-child 规则故无此洞；v2/v3 验收均只断言了段
**颜色**与**点位**，从未断言段**覆盖范围**，低分辨率截图 + 视觉判定两次漏过。

**修复**：`width: 150%`（左缘 stub 半步 + 完整区间到次站中心）。修复后断言：
seg1=[66,174]、衔接缝=0、段尾=2 号点中心（偏差均 0px）、末站右 stub 不变。
验收纪律更新：时间线断言必须包含 `::after` 覆盖范围连续性（seg[i] 尾 == seg[i+1] 头）。
