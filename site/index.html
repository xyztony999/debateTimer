功能特性

从赛前赛制编排到赛后复盘，覆盖一场比赛的完整生命周期。

🖥️

大屏实时同步

意图帧 + 绝对锚点同步：操作秒级直达大屏，断线自动重连并重新校准。

📱

手机遥控与配对码

四位配对码即连，把手机变成瘦遥控器；同一网络自动走 WebRTC 直连。

🔁

自由辩论自动切换

停止一方后另一方自动起表，时间耗尽自动交棒——不必再喊「换表」。

⏳

超时宽限期

可配置宽限秒数：短铃提醒 → 长鸣锁定，两级铃声语义分明，宽限相位同步大屏。

🔔

分级铃声与语音播报

30 秒提醒 / 时间到 / 必须停分级提示音，可选 TTS 语音播报当前阶段。

🗂️

赛制模板与广场

自由编排阶段与计时模式，可发布到公开模板广场一键复用；预置 BP、奥瑞冈等赛制样例。

📊

比赛记录与复盘

自动统计各阶段计划 vs 实绩与超时次数，支持 CSV / JSON 导出。

🌐

三语界面

中文 / English / Français 自由切换，阶段名可分别配置多语言文案。

📲

PWA 与离线可用

可安装到桌面与主屏幕；断网时计时核心照常运行，恢复后自动重连云同步。

三步上手

1

注册即用

浏览器访问 debatetimer.tonyxyz.com/app/，注册后选一套模板或自建赛制即可计时。

2

大屏同步 + 手机遥控

开启大屏同步，大屏扫码只读跟随；用配对码把手机连成遥控器，随时走位控场。

3

赛后复盘

比赛记录自动留存：各环节计划 vs 实绩、超时次数一目了然，导出 CSV 深度复盘。

现在就开一场 →

想自己部署？

一条命令在你的服务器上跑起全栈（页面 + API + MongoDB），支持一体化与 Nginx 反代两种拓扑，适合内网与私有化部署。

bash
git clone https://github.com/xyztony999/debateTimer.git
cd debateTimer
bash deploy/selfhost/setup.sh
