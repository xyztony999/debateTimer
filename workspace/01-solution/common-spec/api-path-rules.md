# API 路径规范（路径豁免与新增接口规约）

| 属性 | 值 |
|------|-----|
| 版本 | v1.0 |
| 状态 | 稳定 |
| 最后更新 | 2026-11-11 |
| 来源 | Gate 1（gate1-full-backfill.md）W-3 裁决项固化 |

## 1. 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 固化本项目的 API 路径命名规则：既有路径豁免范围与新增接口的命名式，供 D3 各 API 文档 M2 自检与后续接口变更引用 |
| 本文档不做什么 | 不改动任何既有路径；不涉及接口行为语义（见各模块 API 文档） |

## 2. 规则

1. **既有路径豁免**：系统已上线的现网路径保持现状、逆向归档不改写——含 `/api/auth/*`（两段式：`/api/auth/<动作>`）、`/api/gallery`、`/api/match-logs`、`/api/admin/*`、`/api/configurations/*`、`/api/session*`、`/api/display/*` 等。各 API 文档 M2 自检对路径偏差统一标注「逆向归档不改路径」即依据本条。
2. **新增接口三段式**：本规则生效后新增的接口一律采用 `/api/<域>/<资源>/<操作>` 三段式命名（域用小写复数或业务域词，操作用动词），与引擎 d3-api.md 分册的路径规范对齐。
3. **既有路径变更**：确需变更既有路径时，视同破坏性变更——必须在对应模块 `changelog.md` 记录变更类型与迁移说明，并同步更新 AA 调用关系与前端 service 层调用点。
4. **判定基准**：「既有」以 2026-11-11 全量补档归档时的现网路由为准（`server/routes/` 七路由文件 + `server/index.js` 挂载表）。
