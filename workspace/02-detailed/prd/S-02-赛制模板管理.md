## 第一部分：PRD 正文

### 1. 业务背景与目标（G1）

一场辩论赛按「赛制模板」推进：阶段序列、各阶段时长与计时模式（单计时/双计时/自由辩论）、多语言阶段名、超时宽限、自动推进开关、对阵队名，以及计时页大屏装饰（PID 时间线）。S-02 让计时操作员与注册用户在比赛前制定并维护这套蓝本，并作为 C-01 比赛计时的直接输入。

服务对象：注册用户与管理员（创建/维护模板）、计时操作员（切换模板与最近使用记忆、队名配置）。模板按账号归属隔离存储。

### 2. 角色与职责（G3）

| 角色 | 职责与权限 | 实现依据 |

#### 3.2 不做什么

- 不做模板导入/导出文件（JSON/文件级）；批量预置导入是服务端脚本，属 D-02。
- 不做模板审批/版本历史/差异对比；保存即覆盖（upsert 保留 createdAt）。
- 不做模板点赞/评论/关注（热度仅广场复制计数，属 S-03）。
- 不做跨账号协作编辑（一个模板只有一个 owner；管理员代管是治理能力而非协作）。
- 不管理比赛过程与实时会话内容：`/session*` 端点虽与本模块同路由文件，业务上属 C-02 大屏同步与远程控制（本文档不展开）。
- 不做发布到广场的业务规则（匿名、下架、复制）——发布仅写 isPublic/creditName 标志，规则见 S-03。
- 不做服务器不可用时的持久离线编辑：仅回落到本地内置只读副本展示（`applyLocalFallback`，`src/DebateSetting.jsx:192-204`）。

#### 5.3 共享与发布联动

- 共享开启或轮换时若无 token 则生成；关闭共享或轮换 token 会立刻终止旧 token 键控的实时会话（大屏回退独立计时）——跨模块联动 C-02（`server/routes/configurations.js:216-220`）。
- 保存/删除/共享/发布变更均 SSE 广播 `{ownerId, name, shareToken?}`，多端同步（`server/routes/configurations.js:117-121,146-151,203-214,362-365`）。
- 发布/撤回与署名规则（creditName ≤20 字符、空串清匿名）业务上属 S-03，写入接口在本模块路由上（见 S-03 PRD §5）。

### 6. 状态与流转（T2）

模板无多状态生命周期（无草稿/审批/生效态）；「未保存编辑态」是前端 UI 状态而非领域状态（保存从「已保存」开始）。两类布尔标志独立翻转：

- `shareEnabled`：关 ↔ 开（开时按需发 token）；翻转/轮换触发会话终止联动。
- `isPublic`：未发布 ↔ 已发布（属 S-03 语义）。

### 7. 业务字段（T1）

模板文档（configurations 集合）：

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| ownerId | ObjectId | 必填 | 归属账号 |
| name | string | (ownerId,name) 唯一；路径段 | 模板名（「默认配置」受保护） |

| timerSettings | map<stageId, mode> | single/double/free | 每阶段计时模式 |
| stageOrder | string[] | 覆盖全部 stageId | 阶段执行顺序 |
| stageLabels | map<stageId, {zh-Hans,en,fr-CA}> | 每语言 ≤40 字符 | 多语言阶段名 |
| stageGrace | map<stageId, 0–300> | 键须为已知阶段 | 超时宽限秒数 |
| stageAutoAdvance | map<stageId, boolean> | 键须为已知阶段 | 阶段结束自动推进开关 |
| teamNames | {aff?, neg?} | 各 ≤20 字符 | 正反方队名 |
| stagePid | map<stageId, {icon?, station?}> | 见 §5.2 | 阶段 PID 装饰 |

### 8. 输入输出规格（T9）

| 接口行为 | 输入 | 输出 / 错误 |
|---------|------|------------|
| 列表 | ?ownerId（仅 admin） | 模板名列表（updatedAt 倒序）；非 admin 带 ownerId → 403 |
| 读详情 | :name（+?ownerId） | 全量字段 + shareEnabled/isPublic/creditName（属主含 shareToken）；404 |
| 保存（upsert） | :name + 白名单字段 | 200「saved successfully」；400 校验失败（message 说明字段） |
| 删除 | :name | 200；404 |
| 共享开关/轮换 | {enabled?, rotate?} | {shareEnabled, shareToken|null}；联动终止旧会话 |
| SSE 订阅 | /stream（Cookie 鉴权） | change 事件；断流由客户端 5s 轮询兜底 |

### 9. 异常与降级（N2）

| 场景 | 行为 |
|------|------|
| 服务器不可用（初始化/加载失败） | 回落本地内置赛制只读展示，提示保存将失败（`src/DebateSetting.jsx:192-204,252-261`） |
| 保存冲突 | 无乐观锁；后写覆盖（upsert），当前实现接受该语义 |
| 校验失败 | 400 + 字段级 message（英文，服务端单一事实源） |
| 删除被 C-01 使用中的模板 | 允许删除；计时页经 SSE 收到变更后按新配置重载（运行中比赛以已加载快照继续） |
| localStorage 不可用（记忆/深链） | try/catch 静默降级到默认模板（`src/config/configConstants.js:9-13,17-21`） |

### 10. 非功能性要求（N1）

- 量级：单用户模板数十级、单模板阶段 ≤64（沿用 S-04 侧上限约定）；文档体量小，无分页（列表一次返回）。
- 同步实时性：SSE 推送毫秒级；轮询兜底 5s。
- 校验均服务端强制，前端约束（maxLength/min/max）仅为输入体验。

### 11. 历史与追溯（N4）

- 模板仅 createdAt/updatedAt，无版本链、无操作日志。
- 遗留兼容：timerSettings 数字 0/1 自动迁移为 single/double（`server/lib/configDocs.js:23-29`）；前端另有 migrateStageConfig 对旧结构迁移（`src/services/configurationShared.js:45-63`）。
