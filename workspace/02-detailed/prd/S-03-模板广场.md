## 第一部分：PRD 正文

### 1. 业务背景与目标（G1）

社团内积累了不少优质赛制模板，但分散在各账号名下。S-03 建立一个公开匿名赛制库（模板广场）：用户可将自己的模板发布上去供他人浏览，任何人（含访客）无需登录即可浏览卡片与详情，登录用户可一键复制他人赛制为自己的模板，管理员可强制下架不当内容。

核心设计约束：**匿名性**——广场所有响应不包含归属人身份与共享凭证，署名仅当属主自愿填写 creditName 时展示。

#### 3.2 不做什么

- **不展示归属人**：列表/详情/计数均不含 owner 身份、shareToken、shareEnabled（投影显式排除，`server/routes/gallery.js:67-76,97-100`）。
- 不做点赞/收藏/评论/关注；热度唯一信号是复制计数。
- 不做内容审核流（无举报/待审队列）；治理手段只有管理员直接下架。
- 不做下架通知/申诉；下架不删除模板，属主模板库中原样保留（仅退出广场）。
- 不做服务端复制端点：复制是客户端「读详情+另存」组合，落在 S-02 的保存接口上。
- 不做广场内编辑：广场只读，修改需复制为自己的模板后进行。
- 不做分页跳页/无限滚动（仅「加载更多」游标续页）。
- 预置导入脚本本身的参数与存储细节属 D-02 系统配置，本文档只约定「可直发广场」这一 S-03 侧语义。

### 4. 领域对象与关系（G4/G5）

| 对象 | 说明 | 关系 |
|------|------|------|

### 6. 状态与流转（T2）

模板在广场视角只有二元可见性状态（存储于 S-02 模板文档）：

```
未发布(isPublic=false) --属主发布--> 已发布(isPublic=true)
已发布 --属主撤回 / 管理员下架--> 未发布
已发布 --模板编辑--> 保持已发布（广场内容实时跟随）
```

- 发布→未发布后，原详情链接立即 404；计数保留（不清零，重新发布热度延续）。
- 下架不删除、不通知属主；属主可在自己的设置页重新发布。

### 7. 业务字段（T1）

广场条目（投影，非独立存储）：

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| id | string | 模板 _id | 详情深链/复制目标 |
| name | string | 模板 name | 卡片标题、搜索目标 |
| stageCount | number | `Object.keys(debateStages).length` | 阶段数 |
| totalSeconds | number | Σ debateStages 值 | 计划总时长（秒） |
| modeSummary | string | timerSettings 计数 | 形如 `single×4 · free×1`；无则为 `—` |
| copies | number | galleryCopyCount | 复制热度 |
| updatedAt | epoch-ms | 模板 updatedAt | 排序与游标 |
| creditName | string? | 模板 creditName | 属主自愿署名，仅存在时序列化 |

发布控制字段（写侧）：`public`（boolean，目标态）、`creditName`（string ≤20，可选）。计数端点无请求体。下架端点无请求体。

详情额外返回模板全量展示字段（schemaVersion、stageOrder、stageLabels、stageGrace、stageAutoAdvance、teamNames 等，经 toDisplayResponse），用于复制落库与阶段明细展示（`server/routes/gallery.js:106-109`）。

### 9. 异常与降级（N2）

| 场景 | 行为 |
|------|------|
| 列表加载失败 | 页面错误态+重试按钮（`src/GalleryPage.jsx:199-203`） |
| 详情不存在/已下架 | 弹窗内 notFound 状态页；深链同样处理（`src/GalleryPage.jsx:265-268`） |
| 复制目标名重复 | 落库 upsert 语义按 S-02 规则（覆盖同名自有模板），前端不额外查重（默认名带副本后缀降低碰撞） |
| 计数上报失败 | 静默降级（热度少计一次，不影响复制成功） |
| 搜索结果为空 | 区分「无匹配」与「广场为空」两种空态文案（`src/GalleryPage.jsx:204-207`） |
| 限流 429 | 429+Retry-After（P-02 格式），前端按请求失败展示 |

### 10. 非功能性要求（N1）

- 列表响应体量：每页 ≤50 条、每条仅摘要字段（无全量阶段配置，列表投影不含 stageOrder/stageLabels 等），控制传输体量。
- 搜索为正则包含匹配，关键字 ≤50 字符且转义；数据量级为社团级（数十至数百公开模板），无性能压力。
- 匿名可访问面在 P-02 有独立限流桶（120/min/IP）。

### 11. 历史与追溯（N4）

- 无发布/下架操作日志（updatedAt 仅反映最后一次变更时间，下架也刷新它，`server/routes/gallery.js:148`）。
- 复制计数无明细（不记复制者与时间）。
- 如实记录：现有实现未提供广场操作的审计追溯。
